Flags (SVG) for AR, CL, MX, CO
------------------------------
Place these files under your web project's /public/flags directory and reference using /flags/<ISO>.svg

Notes:
- MX.svg uses a simplified emblem (small brown circle) for lightweight usage. For full fidelity, replace with an official coat-of-arms vector later.
- All SVGs use simple shapes and a standard viewBox for easy scaling.
- Suggested usage with the CountryFlag component:
  <img src="/flags/AR.svg" width="20" height="20" alt="Argentina" />
